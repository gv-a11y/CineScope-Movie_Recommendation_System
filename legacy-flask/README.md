# Legacy Flask Application Archive

This directory contains the original monolithic Python Flask implementation of CineScope prior to its architectural modernization to:
- **Frontend**: Next.js 14 (App Router) + Apollo Client + Vanilla CSS
- **Backend**: NestJS 10 + GraphQL (Code-First) + Apollo Server + MySQL
- **DevOps**: Docker, Docker Compose, Kubernetes manifests, and Prometheus monitoring

Preserved here for historical reference.
